# Code in the Dark Editor (v2, community)

A modern take on the [Code in the Dark editor](https://github.com/codeinthedark/editor): the same blind, power-mode, single-HTML-file experience, plus optional companions that make a competition easier to prepare and let the audience join in.

> [!IMPORTANT]
> **Running a competition? Use the original editor.** This project is in early planning and nothing here is ready for an event. The [original editor](https://github.com/codeinthedark/editor) is tried and tested — use it until this one has proven itself.

## Status

Planning. The way forward is charted as a wayfinder map on this repo's issues (label `wayfinder:map`). Domain vocabulary lives in [`CONTEXT.md`](./CONTEXT.md).
